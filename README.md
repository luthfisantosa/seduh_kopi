# Seduh Kopi

Panduan seduh kopi dalam satu halaman web: V60 (Tetsu Kasuya 4:6 dan New Yorker), moka pot, French press, dan espresso.

- Kalkulator takaran berdasarkan jumlah cangkir/shot, berat bubuk kopi, atau jumlah kopi jadi (ml)
- Langkah seduh dengan timer yang menandai langkah berjalan
- Mode terang dan gelap mengikuti sistem

**Live:** https://luthfisantosa.github.io/seduh_kopi/

Cukup satu file `index.html`, tanpa build. Buka langsung di browser atau lewat GitHub Pages.
